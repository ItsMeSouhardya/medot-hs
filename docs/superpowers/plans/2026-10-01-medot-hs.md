# MEDOT HS implementation plan

> **For agentic workers:** Use `superpowers:executing-plans` for native execution, task by task. Steps use checkbox syntax for tracking. The user requested the complete planning package together and execution without mandatory per-feature reviewer agents. This plan does not start product implementation; a subsequent implementation request begins M1.

**Goal:** Deliver the existing tactile medicine clip flow with accessible English/Bengali speech, ElevenLabs, pharmacy sign-in, modern design and Render hosting within 22 development hours.

**Architecture:** Import and extend the existing Next.js app at `web/`, retaining Neon SQL, token URLs and pending/readback/activation. Add scoped Clerk authorization, reviewed language variants, deterministic speech and a durable audio cache. Marketing, pharmacy and patient UI share the brand but have separate interaction priorities.

**Tech stack:** Next.js 16.3.6, React 19.2.8, TypeScript, Neon serverless SQL, existing Zod/qrcode/Vitest, Clerk, ElevenLabs direct TTS, CSS variables, one icon family, optional Playwright smoke runner.

**Spec:** [MEDOT product design](../specs/2026-10-01-medot-hs-design.md). Contracts in [Architecture](../../ARCHITECTURE.md); visual decisions in [Design and UX](../../DESIGN_AND_UX.md); test gates in [Quality and release](../../QUALITY_AND_RELEASE.md).

## Global constraints

- Preserve 22-character random tokens, `/m/[token]`, exact NFC/QR URL equality and `PENDING -> ACTIVE -> REVOKED` with independent readback.
- English/Bengali are required; Hindi is planned but optional. ElevenLabs primary, Web Speech explicit fallback. No runtime prescription translation.
- Month-end expiry in Asia/Kolkata; preserve actual physical label values. Patient pages remain public and independent of Clerk.
- One Next.js/Neon app; Render web service; no stack/ORM rewrite. Secrets remain server-only.
- No emojis; icons with accessible labels. UI and README claims reflect observed behavior.
- Only planning files exist in this checkout initially; source remains untouched. Import excludes `.env.local`, dependencies, build output and Git metadata.
- Eight commit milestones, not one commit per checkbox. Mandatory tests/lint/type/build and final integration review; no feature-by-feature human approval loop.

## Review focus

These conditions are pinned to tests below rather than left to a reviewer to discover:

1. A tag revoked while audio is generating must not return its generated bytes (M4).
2. A language switch during fetch/playback must not speak the previous language or medicine (M4).
3. Printed expiry at an India month boundary must change both visual warning and cached audio (M3/M4).
4. A signed-in user outside the pharmacy allowlist must be denied at each resource (M2/M7).
5. English source edited after a demo preset must invalidate its translated instructions (M5).
